纯净版综合盘（只有游戏）需求说明

一、调整总览二、网站端三、飞投（Telegram 机器人 + 小程序）

在现有【播放器】基础上，去掉视频、短视频、聊天相关内容，换一套新的游戏首页和游戏列表布局，生成一个只有游戏的综合盘产品。账户币种改为 USDT，充值只保留 USDT，新增 飞投（Telegram 机器人 + 小程序）。后台、游戏、活动等功能沿用现有系统。

3. 消息中心（底部「客服」）改造

  1. 底部「客服」进入消息中心，页签：客服 / 系统公告 / 站内信。从首页消息图标进入时默认打开「系统公告」。
  2. 客服：标题「7×24 在线客服」+ 说明，下方列出后台配置的客服联系方式（即现在客服弹窗里的内容：头像、名称、「7x24小时在线客服为您服务」、立即咨询），点立即咨询按配置跳转（在线客服页、Telegram 客服账号等）。
  3. 系统公告、站内信：沿用现在的消息中心，内容、可见层级都按后台配置；未读显示红点，页签上显示未读数。点进详情后变为已读。
  4. 系统公告、站内信列表上方新增筛选：时间（今日 / 昨日 / 本周 / 上周 / 本月 / 上月 / 全部）、状态（全部 / 已读 / 未读）、标题搜索；右上角「全部已读」。

4. 其他子页面

个人报表、每日任务、VIP彩金、推广赚钱、安全中心、个人资料、APP下载、活动详情：沿用现有页面，换新皮肤。设置页：个人资料、安全中心、退出登录。

5. 充值（USDT）

  1. 充值中心只展示 USDT 渠道（按协议 TRC20 / ERC20），沿用【播放器】虚拟币类「先选渠道，再输金额，下单后付款」的流程。
  2. 金额以 USDT 输入；上下限、快捷金额、用户手续费、角标优惠取所选渠道 / 栏目配置；显示支付数量、手续费、到账数量。
  3. 下单后进入付款页：二维码、收款地址、协议、转账数量、订单号、倒计时；「我已完成转账」回到交易记录，链上确认后自动到账；可取消订单。

6. 提现与收款方式

  1. 只提现到 USDT 地址；未绑定时先引导添加。添加需选择协议、填地址和备注、短信验证码，按协议校验地址格式，最多 3 个。
  2. 金额以 USDT 输入，显示手续费、到账数量、剩余打码量；打码量未完成不可提交。

7. 我的 / 更多

  1. 保留交易记录、投注记录（可按网站 / 飞投筛选）、个人报表、每日任务、VIP彩金、推广赚钱、收款方式、安全中心、客服中心、APP下载、设置。
  2. 新增「飞投」卡片，显示 Telegram 绑定状态。

三、飞投（Telegram 机器人 + 小程序）

1. 是什么

「飞机」即 Telegram。飞投由一个 Telegram 官方机器人和一个 Telegram 小程序组成。机器人负责注册 / 绑定、账号信息、充值、提现入口、客服和 APP 下载；点「进入游戏」就在 Telegram 里打开整个网站（小程序），免登录，游戏都在小程序里玩。玩家不用记网址、不用下载 APP，在 Telegram 里就能完成注册、充值、游戏、提现。

配套官方频道、客服 Telegram 账号、代理招商 Telegram 账号，链接都在后台配置。

2. 入口

  1. 网站：首页账户卡片「飞投」、底部导航「飞投」、我的页飞投卡片 → 网站飞投页 → 打开机器人。
  2. Telegram：搜索机器人、官方频道里的链接、推广链接。

3. 首次进入（未注册 / 未绑定）

  1. 机器人主页显示「开始」按钮；点击后机器人依次发送：
    • 欢迎卡片：宣传图 + 机器人介绍（平台卖点「U存U提·匿名无忧」、游戏分类、代理合作联系方式、官方网址 / 频道 / 飞投 / 客服）。
    • 一句口号。
    • 「请选择绑定或注册账号」，按钮「👤 注册账号」「🔗 绑定账号」。
  2. 从网站飞投页点「绑定 Telegram」进来的，点「开始」后直接绑定当前网站账号，不再出现注册 / 绑定选择。

4. 注册账号

  1. 点「注册账号」即用当前 Telegram 身份一键注册，无需填写任何信息；注册来源记为「Telegram」。
  2. 系统自动生成会员账号和登录密码。机器人回复「🏆 欢迎使用 XX 投注小程序」和账号卡片：会员ID、会员账号、会员密码、USDT 余额、VIP 等级。会员密码只在注册成功这条消息里显示，玩家可用它在网站 / APP 登录。
  3. 网站和 APP 需要支持「账号 + 密码」登录（Telegram 注册的账号没有手机号）；玩家可在安全中心补绑手机号。
  4. 已注册的 Telegram 再点「开始」，回复「您已经注册，无需再次注册。」

5. 绑定账号

  1. 点「绑定账号」，机器人回复「请在小程序中登录要绑定的网站账号」+「🔐 登录绑定」按钮；点击在小程序打开登录页，登录成功即绑定，机器人回复绑定成功和账号卡片。
  2. 一个网站账号只能绑一个 Telegram，一个 Telegram 只能绑一个网站账号；已被占用时提示「该 Telegram 已绑定其他账号」。
  3. 解绑在网站飞投页操作，需短信验证码。

6. 底部快捷菜单

注册 / 绑定后，输入框下方常驻 6 个按键，两列排列：🏠 账号信息、🎮 进入游戏、💰 充值、💳 提现、👧 官方客服、📲 下载APP。点击等于发送这句话。

7. 各功能回复

功能机器人回复消息下方按钮
账号信息「🏆 欢迎使用 XX 投注小程序」+「您的账号信息」：会员ID、会员账号、USDT 余额、VIP 等级（不显示密码）🎮 进入游戏（小程序）；💳 提现（小程序）、👧 官方客服；📲 下载APP、💰 充值
进入游戏不发消息，直接打开小程序首页—
充值「✅ 用户充值 / 💰 充值 / 💵 余额：x USDT」各 USDT 渠道（如 💵 TRC20、💵 ERC20，按后台开启的渠道）、📃 充值记录；👧 官方客服、📲 下载APP；↩️ 返回
· 选渠道「请回复您要充值的金额（下限-上限）」，范围取该渠道单笔上下限🚫 取消订单
· 回复金额超出范围：「金额需在 x-x 之间，请重新回复」。通过：生成充值订单，回复订单信息：订单号、充值金额、手续费、到账金额、协议、收款地址、收款二维码、30 分钟有效提示📋 复制地址；🚫 取消订单
· 结果推送链上到账：「✅ 充值成功」+ 到账金额 + 余额；超时：「充值超时，订单失效」；取消：「订单已取消」到账后附 🎮 进入游戏

官方客服两行：「点击联系客服　官方客服 - TG客服」「点击联系客服　官方客服 - 在线客服」。TG客服跳到客服的 Telegram 账号私聊；在线客服在小程序打开在线客服页—
下载APP「Android Download ● 原生APP」「IOS Download ● 原生APP ● iOS描述签」，均为下载链接—
其他文字「请使用下方菜单操作 👇」—
未注册时点功能「请先注册或绑定账号」👤 注册账号；🔗 绑定账号

消息下方按钮里，带小程序图标的会在 Telegram 内打开小程序；普通按钮在聊天里继续回复。

8. 小程序

  1. 小程序就是本网站页面在 Telegram 内打开：顶部显示机器人名称，右上角 ✕ 关闭回到聊天，底部显示机器人账号。
  2. 已绑定 Telegram 自动登录，页面、游戏、充值、提现、活动与网站完全一致。
  3. 在小程序里下的注单，来源标记「飞投」，在投注记录里可按网站 / 飞投筛选；同样计入打码量、返水、VIP 成长和报表。

9. 与网站的数据关系

  1. 同一账户、同一 USDT 余额；机器人里充值生成的订单与网站充值订单相同，在交易记录中可见。
  2. 网站发起的充值到账、提现结果，已绑定 Telegram 的玩家也会收到机器人推送。

10. 后台需要能配置

  1. 机器人、官方频道、客服 Telegram 账号、在线客服、APP 下载（安卓 / iOS / iOS描述签）链接；没配置的按钮和文字不显示。
  2. 欢迎卡片的宣传图和介绍文案、口号。
  3. 充值渠道沿用 USDT 支付渠道配置。
