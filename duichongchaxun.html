一、查询方式（异步任务，交互参照全量导出）
  • 页面结构：对冲查询页上方为查询条件区，下方为查询任务列表；点击任务的【查看结果】进入查询结果页，结果页左上角提供【返回查询任务】入口。
  • 提交查询：填写查询条件后点击【提交查询】，系统生成一条查询任务在后台处理，页面不等待结果。提交成功后在查询区下方提示"查询任务已提交，处理完成后可在下方列表点击【查看结果】"，新任务置顶显示在任务列表首行。提交后用户可离开本页，任务继续处理。
  • 提交校验：
    - 查询条件均为必填，未填写时提示补全，不生成任务。
    - 所选彩种暂无可对冲玩法时，直接提示"该彩种暂无可对冲玩法"，不生成任务。
    - 同一后台账号已有相同查询条件（彩种、当前期数、目标会员、追溯历史期数、命中对冲期数均相同）的任务在排队或处理中，提示"相同条件的查询任务正在处理中，请勿重复提交"，不生成任务。
    - 同一后台账号同时排队或处理中的任务最多 3 个，超出时提示"当前已有 3 个查询任务正在处理，请等待完成后再提交"。
  • 任务列表：展示本商户后台账号提交的查询任务，按提交时间倒序，分页展示。列表内容：任务编号、查询条件（彩种、当前期数、目标会员、追溯历史期数、命中对冲期数）、提交人、提交时间及完成时间、状态、结果、操作。
  • 任务状态：排队中 → 处理中（展示处理进度）→ 已完成 / 失败；已完成的任务超过 7 天变为已过期。列表中存在排队中或处理中的任务时自动刷新状态，也可点击【刷新】手动更新。
  • 结果列：已完成的任务直接显示命中的疑似对冲关系个数及涉及期数；没有命中时显示"未命中"。其他状态显示"—"。
  • 操作列：
    - 已完成：【查看结果】，进入查询结果页（未命中也可进入，结果页显示空状态提示）。
    - 处理中 / 排队中：不可操作，提示"处理完成后可查看"。
    - 失败：状态旁"?"悬浮显示失败原因；操作为【重新提交】，按原查询条件生成一条新任务，原失败任务保留。
    - 已过期：提示"结果已过期"，需重新提交查询。
  • 查询结果页：顶部展示本次任务的任务编号、查询条件及结果生成时间。结果为任务完成时的数据，之后不再变化；如需最新数据，请重新提交查询。结果页的列表、筛选、详情、规则说明交互见下方第二部分。
  • 结果保留：查询结果保留 7 天，过期后不可查看。
二、对冲判定与结果展示
  • 查询范围：以【当前期数】为起点往前推 N 期（含当前期，N=追溯历史期数），检索目标会员在这些期内的注单，与全平台（含其他商户）同彩种同期注单进行比对。
  • 单人对冲：同一彩种、同一期、同一可对冲玩法下，其他会员投注了与目标会员相反的选项（如大/小、单/双），且金额与目标会员在该选项上的金额相等，即判定为对冲。
    - 只要任意一个玩法满足即算，不要求双方投注玩法个数相同，双方的其他玩法不影响判定。例：目标会员下大100、双50、豹子20，对方只下小100，算对冲。
  • 组合对冲：同一期、同一玩法下，两名会员都投注了与目标会员相反的选项，且两人金额之和等于目标会员金额，判定为组合对冲。最多只按 2 人组合判定。
    - 单个会员金额已与目标会员相等的，按单人对冲处理，不再参与组合。
    - 同一期可能出现多个组合（如目标下小100，B、C、D 各下大50，则 B+C、B+D、C+D 均为组合），每个组合分别判定、分别统计。
  • 命中对冲期数（累计，不要求连续）：按"对冲关系"分别统计——单人对冲按同一会员统计，组合对冲按同一对会员组合统计。某对冲关系在 N 期内与目标会员形成对冲的期数累计 ≥ M（M=命中对冲期数）时列出。同一期内同一对冲关系在多个玩法上都对冲，只计 1 期。
  • 列表展示：按期数倒序，每期一组（期数、操作单元格合并），组内首行为目标会员，其后为该期命中的对冲会员；按该彩种的对冲玩法分列展示各会员的投注金额，参与对冲的金额加粗高亮。
    - 对冲会员账号后显示标签：疑似单人对冲 / 疑似组合对冲N（组合编号在本次查询结果内固定）；同一会员同期参与多个组合时打多个标签。
    - 列表上方展示本次命中的全部对冲关系及其命中期数，点击可筛选只看该关系涉及的期数。
  • 列表玩法列：只展示所选彩种的可对冲玩法（见下方"对冲玩法定义"），列固定，不随查询结果增减；某玩法本期无人下注时该列留空。
    - 每格展示该会员本期在该选项上的投注总额（不论是否参与对冲），参与疑似对冲的金额加粗高亮。
    - 非对冲玩法（如豹子、豹顺、特码等）不单独成列，合计金额展示在最后的"其他玩法"列，无则留空；明细在详情中查看。
  • "疑似"文案：查询结果仅为按规则筛出的疑似对冲，由商户自行判断。页面中所有描述判定结果的文案均需带"疑似"，包括：任务列表结果列、结果汇总、对冲关系筛选项、对冲标签、详情标题、本期对冲关系、注单明细中的对冲标记。功能名称（对冲查询、对冲规则说明）、查询条件名称及任务状态不加。
  • 商户区分：与目标会员同商户（包括子商户）的会员，整行数据红色字体，账号完整显示，括号内显示所属商户名；其他商户的会员，整行数据黄色字体，账号只显示前2位+***+后4位，括号内显示"其他"。
  • 账号保护：其他商户会员的完整账号在页面、详情及任务结果中均不得出现，一律显示脱敏账号。
  • 详情展示：按期查看，顶部列出该期所有对冲关系的金额对应；下方展示目标会员及该期全部对冲会员在本期的所有投注（包括非对冲玩法，如豹子、豹顺等），命中对冲的投注高亮标注。
  • 规则说明：查询页及结果页均提供"对冲规则说明"入口，用通俗文字和例子向商户说明判定规则、颜色含义及查询任务的使用方式，内容见页面弹窗。

对冲规则说明

查询结果只是按下注规律筛出来的"疑似对冲"，系统不会自动处理，是否真的在刷流水请商户结合实际情况自己判断。

一、怎么查询

填好查询条件点【提交查询】，系统会在后台慢慢查，不用一直等在页面上。下方"查询任务"里可以看到进度，状态变成"已完成"后点【查看结果】就能看到疑似对冲列表。
查询结果保留 7 天，过期后需要重新提交。查询失败的任务可以点【重新提交】再查一次。

二、什么是对冲

同一个彩种、同一期，目标会员下了一边（比如"大"），另一个会员下了相反的一边（"小"），而且金额一样，就算一次对冲。这样两人不管开什么都一输一赢，只是在刷流水。
例：第088期，A 下"大"100元，B 下"小"100元 → A 和 B 对冲。

三、只要有一个玩法对上就算

不需要两人下的玩法一模一样，只要其中一个玩法是反着下、金额一样，就算对冲。其他玩法不影响。
例：A 下了"大"100、"双"50、"豹子"20，B 只下了"小"100 → 也算对冲。点"详情"可以看到双方这一期下的所有注单。

四、两个人凑一起也算（组合对冲）

两个会员都下了相反的一边，两人金额加起来刚好等于目标会员的金额，也算对冲，叫"组合对冲"。最多只看两个人的组合。
例：A 下"小"100，B 下"大"50，C 下"大"50 → B+C 组合对冲，列表里 B 和 C 后面会标"疑似组合对冲1"。
如果同一期还有 D 下"大"50，那 B+D、C+D 也都会算成组合，分别打上不同的组合标签；一个人参与了几个组合就会有几个标签。

五、命中对冲期数怎么算

在"追溯历史期数"里，同一个对象（某一个会员，或者某两个会员的固定组合）跟目标会员对冲的期数加起来，达到"命中对冲期数"就会列出来。不需要连续，同一期在多个玩法上对冲也只算 1 期。
例：追溯 50 期、命中对冲期数填 10。B 在这 50 期里有 12 期跟 A 对冲 → 列出；C 只有 6 期 → 不列出。

六、颜色和账号怎么看

  • 红色：跟目标会员同一个商户（包括子商户）的会员，显示完整账号和商户名。
  • 黄色：其他商户的会员，账号只显示前2位和后4位（如 60***1022），商户显示为"其他"，但仍可以查看详情。

七、列表里显示哪些玩法

列表只显示这个彩种可以对冲的玩法（如大、小、单、双），每格是这个会员这一期在该选项上下注的总金额，参与疑似对冲的金额会加粗标黄。
其他玩法（如豹子、特码）不单独列出，合计金额放在"其他玩法"一列，具体下了什么点"详情"查看。

八、哪些玩法算"相反"

  • 快三、鱼虾蟹、PC28、六合彩类：大 / 小、单 / 双
  • 赛车：大 / 小、单 / 双、冠亚和大 / 和小、和单 / 和双
  • 时时彩、11选5：第一球大小单双、总和大小单双
  • 快乐十分：第一球、第八球、总和的大小单双
  • 百人牛牛：蓝方胜 / 红方胜、龙 / 虎；极速百家乐：庄 / 闲
