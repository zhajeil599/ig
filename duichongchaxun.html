对冲规则说明

一、什么是对冲

同一个彩种、同一期，目标会员下了一边（比如"大"），另一个会员下了相反的一边（"小"），而且金额一样，就算一次对冲。这样两人不管开什么都一输一赢，只是在刷流水。
例：第088期，A 下"大"100元，B 下"小"100元 → A 和 B 对冲。

二、只要有一个玩法对上就算

不需要两人下的玩法一模一样，只要其中一个玩法是反着下、金额一样，就算对冲。其他玩法不影响。
例：A 下了"大"100、"双"50、"豹子"20，B 只下了"小"100 → 也算对冲。点"详情"可以看到双方这一期下的所有注单。

三、两个人凑一起也算（组合对冲）

两个会员都下了相反的一边，两人金额加起来刚好等于目标会员的金额，也算对冲，叫"组合对冲"。最多只看两个人的组合。
例：A 下"小"100，B 下"大"50，C 下"大"50 → B+C 组合对冲，列表里 B 和 C 后面会标"组合1"。
如果同一期还有 D 下"大"50，那 B+D、C+D 也都会算成组合，分别打上不同的组合标签；一个人参与了几个组合就会有几个标签。

四、命中对冲期数怎么算

在"追溯历史期数"里，同一个对象（某一个会员，或者某两个会员的固定组合）跟目标会员对冲的期数加起来，达到"命中对冲期数"就会列出来。不需要连续，同一期在多个玩法上对冲也只算 1 期。
例：追溯 50 期、命中对冲期数填 10。B 在这 50 期里有 12 期跟 A 对冲 → 列出；C 只有 6 期 → 不列出。

五、颜色和账号怎么看

  • 红色：跟目标会员同一个商户（包括子商户）的会员，显示完整账号和商户名。
  • 黄色：其他商户的会员，账号只显示前2位和后4位（如 60***1022），商户显示为"其他"，但仍可以查看详情。

六、哪些玩法算"相反"

  • 快三、鱼虾蟹、PC28、六合彩类：大 / 小、单 / 双
  • 赛车：大 / 小、单 / 双、冠亚和大 / 和小、和单 / 和双
  • 时时彩、11选5：第一球大小单双、总和大小单双
  • 快乐十分：第一球、第八球、总和的大小单双
  • 百人牛牛：蓝方胜 / 红方胜、龙 / 虎；极速百家乐：庄 / 闲
