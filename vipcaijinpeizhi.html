需求说明（研发必读，实际前端不展示给用户看）

  1. 金额显示规则： 所有的金额字段（充值、打码、工资、封顶等）前端展示时，默认删除无效数字0（例如 10.00 展示为 10，10.50 展示为 10.5）。
  2. 输入框限制： 弹窗中带 * 号的为必填项。等级必须为连续正整数；各项金额（充值、打码、奖励、封顶）必须为大于等于 0 的数字，输入限制至多10位数字，且最多允许输入两位小数。
  3. 关键字段含义：
    • 当日充值 / 当日打码： 触发或领取对应奖励所必须满足的单日充值和有效投注门槛条件。
    • 晋级奖励： 达到对应等级条件后，发放给玩家的彩金奖励。
    • 日/周/月累计封顶： 限制玩家在该周期内，领取该项奖励的最大总金额上限，防止超发。
  4. 公共配置含义：
    • 稽核倍数： 玩家提现该笔福利彩金前需要完成的流水倍数（填 0 意味着免稽核直接可提）。
    • 晋级时是否重复领取： 控制跨级晋升时，是叠加领取所有途径等级的奖励，还是只发最高级别的奖励。
    • 奖励领取过期天数： 逾期未领取的奖励将自动失效无法领取，设置为 0 则表示永久有效。
  5. 删除交互： 点击删除按钮须弹出二次确认框，点击“确定”后再请求接口并刷新当前列表。
