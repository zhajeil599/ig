VIP彩金（晋级奖励 / 周工资 / 月工资）需求说明

更新：2026-11-05 · 包含后台「VIP彩金配置」与前台「升级模式」页面

一、后台 · VIP彩金配置列表

  1. 列表字段：等级、总存款；晋级奖励（充值要求、打码要求、晋级奖励）；月工资（充值要求、打码要求、月工资）；周工资（充值要求、打码要求、周工资）；状态、创建时间、操作（修改 / 删除）。按等级从小到大排序。
  2. 表头随配置变化：各奖励下的「充值 / 打码」表头按公共配置中的统计周期显示，例如月工资选「上月」时显示「上月充值 / 上月打码」。
  3. 表头提示：「晋级奖励 / 月工资 / 周工资」后带「?」，悬停显示该奖励的领取时间、统计周期与过期规则，内容由公共配置自动生成。例：
    • 月工资：每月1号领取，过期不可领取；领取条件按上月充值/打码统计
    • 周工资：每周一领取，过期不可领取；领取条件按上周充值/打码统计
  4. 金额展示：所有金额去掉无效的 0，如 10.00 显示 10，10.50 显示 10.5。
  5. 查询：按等级精确查询；「重置」清空条件并刷新列表。

二、后台 · 新增 / 修改等级

项目规则
等级 *正整数，等级需连续。新增时只能填当前最高等级 + 1（无等级时为 1）；修改时不可改。
总存款 *会员累计充值达到该金额即晋升到此等级。需大于上一等级、小于下一等级的总存款。
充值要求 / 打码要求领取该项奖励需满足的充值金额、有效投注门槛，统计周期取公共配置。填 0 表示无该项要求。
晋级奖励 / 月工资 / 周工资发放金额。填 0 表示该等级无此奖励，前台显示「暂无」。
状态 *默认开启。关闭后前台不展示该等级，会员不可领取该等级的各项奖励；会员等级晋升不受影响。
输入限制金额类均为 ≥ 0 的数字，整数部分最多 10 位，最多 2 位小数；不填按 0 处理。

删除

  • 点击删除弹出二次确认，确定后删除并刷新列表。
  • 为保证等级连续，只能删除当前最高等级；删除其他等级时提示「请先删除更高等级」。

三、后台 · 公共配置

配置项选项 / 默认说明
稽核倍数 *默认 1领取的彩金需完成「彩金金额 × 倍数」的有效投注后方可提现，0 表示不需要稽核。三类奖励共用。
晋级奖励配置
领取条件统计周期当日 / 上周 / 上月，默认当日判断充值、打码要求时统计的时间范围（定义见第四节）。
跨级领取可领取途经所有等级 / 只能领取最高一档，默认可领取途经所有等级一次晋升多个等级时，是每个途经等级的晋级奖励都可领，还是只可领到达的最高等级奖励。
奖励领取过期天数 *默认 30从达到该等级起算，逾期未领取的晋级奖励失效；0 表示永久有效。
周工资配置 / 月工资配置（规则相同）
领取条件统计周期当日 / 上周 / 上月；周工资默认上周，月工资默认上月判断充值、打码要求时统计的时间范围。
领取时间随时可领取 / 指定日期领取；默认指定：周工资每周一，月工资每月1号指定日期时：周工资可选周一至周日；月工资可选 1–28 号（保证每个月都有该日）。
文案内容富文本展示在前台「活动详情」顶部。

四、领取规则

4.1 统计周期定义（按站点时区）

  • 当日：领取当天 00:00:00 至领取时刻的累计充值 / 有效投注。
  • 上周：上一个自然周（周一 00:00:00 至周日 23:59:59）。
  • 上月：上一个自然月（1号 00:00:00 至月末 23:59:59）。
  • 充值、打码两项要求需同时满足才可领取。

4.2 晋级奖励

  • 会员累计充值达到某等级总存款即视为达到该等级，该等级晋级奖励进入可领取范围，每个等级只能领取一次。
  • 领取时需满足该等级配置的充值、打码要求（按晋级奖励的统计周期计算），未满足时前台显示具体差额要求。
  • 跨级晋升：选「可领取途经所有等级」时每级都可领；选「只能领取最高一档」时，低于最高等级且尚未领取的等级显示「不可领取」。
  • 达到等级后超过过期天数未领取，该等级显示「已过期」，不可再领。
  • 不设领取金额封顶。

4.3 周工资 / 月工资

  • 按会员领取时的当前等级发放该等级的周 / 月工资，每个自然周 / 自然月只能领取一次。
  • 领取时需满足当前等级配置的充值、打码要求（按各自统计周期计算）。
  • 领取时间为「指定日期」时：仅当天可领，当天 23:59:59 未领取即过期，不可补领。
  • 领取时间为「随时可领取」时：本周 / 本月内任意时间可领，周期结束未领取即过期。
  • 不设领取金额封顶。

4.4 稽核

  • 每笔领取的彩金按领取时的稽核倍数生成稽核要求，完成后方可提现。

五、前台 · 升级模式页面

5.1 周俸禄 / 月俸禄按钮

状态展示
可领取金色按钮「立即领取」，点击提示「领取成功」后变为已领取。
未到领取时间灰色，显示「每周一领取」/「每月1号领取」。
未达标灰色，显示差的条件，例：「需上周充值 1000 / 需上周有效投注 10000」。
本期已领取灰色，显示「下周再来」/「下月再来」。
当前等级无此奖励灰色，显示「暂无」。
  • 按钮下方展示领取提示，文案由后台配置自动生成，例：「周俸禄每周一领取，月俸禄每月1号领取，过期不可领取」。

5.2 等级可领列表

  • 展示所有开启的等级，每个等级显示领取条件（含统计周期，例「需当日充值 40 / 需当日有效投注 200」）和晋级奖金额。
  • 按钮状态：立即领取 / 未达标 / 已领取 / 不可领取（只领最高一档时）/ 已过期 / 等待升级（未达到该等级）。

5.3 其他

  • 顶部表盘、总充值、当前等级卡片（距离下一级的充值差额）按会员实际数据展示。
  • 活动详情：上方为后台文案内容；下方表格展示各等级总存款、晋级礼金、周俸禄、月俸禄，金额下方附带领取条件（如「上周充100 / 投1000」），金额为 0 的格子只显示 0。
  • 领取记录：展示日期、金额、类型（晋级礼金 / 周俸禄 / 月俸禄）、详情（如「v3-晋级礼金」），按时间倒序。
